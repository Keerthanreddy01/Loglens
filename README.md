# LogLens 🔍

**Enterprise-grade log analytics and visualization platform for modern infrastructure teams.**

LogLens transforms raw logs into actionable insights with real-time analysis, AI-powered intelligence, and a premium, cinematic user interface. Built with Next.js, TypeScript, and WorkOS AuthKit.

## ✨ Features
- ⚡ **Real-Time Log Analysis** - Parse and visualize log streams instantly.
- 🤖 **AI-Powered Insights** - Intelligent log interpretation.
- 🔒 **Enterprise Authentication** - Powered by WorkOS AuthKit.
- 🎨 **Premium Modern UI** - Dark theme with smooth animations.
- 📈 **Interactive Dashboards** - Rich data visualizations.

## 🚀 Quick Start

### Prerequisites
- Node.js >= 20.x
- WorkOS Account

### Installation

```bash
git clone https://github.com/Keerthanreddy01/Loglens.git
cd Loglens
npm install
cp .env.example .env.local
```

Edit `.env.local` with your WorkOS credentials, then run:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
